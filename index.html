※ 登録者が1,000人を超えると、YouTube は数を丸めて返します（例 1,234人 → 1,230人）。

API キーが空のあいだは、プレビューにデモの数字が出ます。キーは URL に入るので、URL を人に見せたり、配信画面に映したりしないでください。

API キーの作り方
  1. Google Cloud コンソールに Google アカウントでログインし、新しいプロジェクトを作る
  2. 「API とサービス」→「ライブラリ」で YouTube Data API v3 を探して「有効にする」
  3. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」
  4. できたキーの「キーを制限」で、API の制限を「YouTube Data API v3」だけにする。アプリケーションの制限を「ウェブサイト」にして、公開先のアドレス（例 https://yotuba12.github.io/*）を入れる
  5. キーをコピーして、上の欄に貼る

無料の範囲で使えます。高評価数は1分ごとに取得します。
