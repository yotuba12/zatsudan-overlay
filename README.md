# 雑談オーバーレイ

PRISM Live Studio（スマホ版）の「Web」ウィジェットで使う、YouTube 雑談配信用のオーバーレイです。

- 現在時刻（24時間・秒あり）と配信時間
- 高評価・チャンネル登録者の目標バー（YouTube Data API で自動更新）
- 2段のテロップ
- 背景の透過率、目標バーとテロップを一定時間ごとに隠す設定

## 使い方

1. 設定ページ（`index.html`）を開いて内容を入力する
2. 「コピー」で URL をコピーする
3. PRISM の My Studio → ウィジェット → 「Web」に貼り付けて、画面いっぱいに広げる

API キーは URL の中にだけ入り、このリポジトリには含まれません。
